# Business Agent foundation

Preserve the domain-oriented Markdown runtime, remove the unrelated job-review
product path, and establish typed seams for skills, tools, Microsoft execution,
MCP, and local evaluation.

Non-goals are live Azure provisioning, external side effects, and production
retrieval until credentials and service configuration are available.

Acceptance criteria are a passing typecheck, passing tests, a successful web
build, an offline land-administration flow, and documentation that distinguishes
local proof from cloud-dependent work.
